# Escolinha Top Vôlei

Site do projeto social **Escolinha Top Vôlei** — aulas gratuitas de vôlei de areia para
crianças e adolescentes de 6 a 16 anos na Praça Tenente Lucena, Castelo Branco, João
Pessoa/PB.

> Formação · Disciplina · Superação · Amizade

## Sobre o projeto

A Escolinha é mantida com recursos próprios e trabalho voluntário. Não há mensalidade nem
taxa de inscrição. As aulas acontecem nos sábados e domingos, normalmente das 15h às 17h, e
são abertas a todos os níveis — não é preciso saber jogar.

O projeto liga esporte e educação: boas notas e frequência escolar fazem parte do
compromisso de quem treina.

## Para desenvolvedores

Site estático construído com [Astro](https://astro.build).

```bash
npm install          # instala as dependências
npm run dev          # http://localhost:4321
npm run verificar    # lint + tipos + build
npm run test:e2e     # testes num navegador real
```

### Antes de contribuir

O fluxo é **Issue → Branch → Commits → Pull Request → Merge → Deploy**. Nada vai direto
para a `main`.

Commits seguem [Conventional Commits](https://www.conventionalcommits.org/pt-br/).

### Aviso importante

Este repositório é **público**. Fotos de crianças sem autorização de uso de imagem
assinada pelos responsáveis **não podem** ser versionadas — a pasta
`assets-originais/fotos-sem-autorizacao/` está no `.gitignore` por esse motivo e a linha
não deve ser removida.

## Apoie

O projeto aceita patrocínio, doação de material (bolas, redes, uniformes), voluntariado e
parcerias para bolsas de estudo. Fale pelo WhatsApp acima.
